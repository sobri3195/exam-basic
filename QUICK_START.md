# 🚀 Quick Start Guide - Exam Basic

## Langkah Cepat

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Aplikasi
```bash
npm run dev
```

### 3. Buka Browser
```
http://localhost:5173
```

### 4. Mulai Ujian
1. Masukkan nama Anda
2. Pilih paket ujian (atau "Semua Paket")
3. Klik "Mulai Ujian"
4. Kerjakan soal (15 menit)
5. Lihat hasil & review jawaban

## 📂 Files Penting

- `src/data/questions.json` - Tambah/edit soal di sini
- `src/pages/Exam.jsx` - Ubah durasi ujian (line 12)
- `src/index.css` - Custom styling

## 🎨 Fitur Utama

✅ Timer 15 menit dengan auto-submit
✅ Soal diacak otomatis
✅ Jawaban tersimpan otomatis (aman dari refresh)
✅ Review lengkap dengan penjelasan
✅ Responsive mobile & desktop
✅ 10 soal contoh dari 5 topik
